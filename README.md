# Amazon Clone (Homepage UI)

A front-end recreation of the Amazon homepage built with plain HTML and CSS, focused on layout accuracy and UI detail.

## Features
- Dark navigation header with logo, "Deliver to" location, search bar with category dropdown, account, returns & orders and cart
- Secondary navigation bar (All, Today's Deals, Customer Service, Registry, Gift Cards, Sell)
- Hero banner with category cards such as Kid's Section, Mobiles and Smartwatches
- Hover outlines on header items, like the original site
- Font Awesome icons

## Tech Stack
HTML5, CSS3 (Flexbox), Font Awesome
